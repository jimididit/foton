How to read the tiers

Tier 1 - Observed artifact. Directly present in the collected data, no interpretation applied. A registry value, an event ID, a signature status. State these as fact.

Tier 2 - Supported inference. A reasonable reading of one or more Tier 1 artifacts where other readings remain possible. An unsigned binary in AppData holding an outbound connection is consistent with C2 and equally consistent with a portable application. Cite the artifact and name the assumption.

Tier 3 - Unverified hypothesis. Not stated as findings by this tool. If you form one during analysis, record what evidence would move it to Tier 2.
